# WhatsApp Message Router AI

## Overview
A production-quality AI system designed to analyze, classify, and route incoming messages based on conversational context (personal, group, business). Built for an AI competition, prioritizing accuracy, maintainability, and robustness.

## Folder Structure
- `code/`: Main application source code.
- `dataset/`: Raw and processed data files (CSVs).
- `tests/`: Unit and integration tests.
- `docs/`: Additional documentation.
- `cache/`: Temporary data caching.
- `outputs/`: Generated artifacts or output files.
- `logs/`: Application execution logs.
- `prompts/`: LLM prompt templates.
- `configs/`: Configuration files (YAML/JSON).

## Setup
1. Install dependencies: `pip install -r requirements.txt`
2. Follow `architecture.md` for system design.
